# Freddai Shorts

14 vertical (1080x1920, 30 fps) Shorts: 10 main shorts plus 4 "-dd" variants that open with Denis on camera.
Plan and narration: `SHORTS-PLAN.md`. UI notes: `UI-KIT.md`.

## Files
- `remotion-project/` Remotion 4 project. Raw renders land in `remotion-project/out/<id>.mp4`.
- `deliver/<id>.mp4` loudness masters (-14 LUFS, -1.5 dBTP, video stream copied, AAC 320k).
- `deliver/web/<id>-web.mp4` web encodes (CRF 24, AAC 160k, faststart).
- `deliver/thumbs/<id>.jpg` frame 0 at full size (Shorts thumbnails).
- `deliver/sheets/<id>.jpg` 1 fps contact sheets for review.
- `deliver/YOUTUBE.md` titles, descriptions, hashtags.
- `v2/` second batch (ids 11-20), not part of this delivery.

## Re-render one short
```
cd remotion-project
npx remotion render src/index.ts short-05-needsyou out/short-05-needsyou.mp4 \
  --browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```
Then master it: two-pass loudnorm (measure with `loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json`, then apply with the measured_* values and `linear=true`) with `-c:v copy -c:a aac -b:a 320k -movflags +faststart`, and the web encode `-c:v libx264 -crf 24 -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart`. Reference script: `~/.claude/skills/promo-film/scripts/master.sh`.
Check types first with `npx tsc --noEmit`.

## Where things live (remotion-project/src/shorts/)
- Scenes: one component per short, `Short01Limit.tsx` ... `Short10Hands.tsx`; shared pieces `ShortShell`, `HookTitle`, `Captions`, `Turn`, `EndCard`, `OldWay`, `ShortAudio`.
- Timelines: `timelines.ts` (`SHORT_TIMELINES`: VO line start/duration, cues, music turn/lift/hit, sfx). Frame counts come from `durationInFrames` there.
- Narration: text in the timelines and `SHORTS-PLAN.md`; Hume audio in `public/vo/<short>-<line>.mp3` (generated by `tools/vo-hume.cjs`). Music: `tools/music-warm.cjs`; sfx: `tools/sfx-synth.cjs`.
- Registration: `registry.ts` collects `groupA..E.ts` (and V2 groups); each group lists `{ id, durationInFrames, component }`, and `src/Root.tsx` turns them into compositions.

## Add a short
1. Add its lines to the plan and generate VO into `public/vo/`.
2. Add an entry to `SHORT_TIMELINES` in `timelines.ts`.
3. Write `ShortNN<Name>.tsx` using `ShortShell`, `HookTitle` (hook visible at frame 0) and `EndCard`.
4. Register `{ id: "short-NN-name", durationInFrames, component }` in a group file.
5. `npx tsc --noEmit`, render, master, add to `deliver/YOUTUBE.md`.

## How the dd variants work
`ShortDd.tsx` builds `short-NN-<name>-dd` for limit, usage, voice, office. Config per variant (`CFG`): the Denis clip (`public/denis/<clip>.mp4`, word timings in `public/denis/clips.json`), the base short component, and the hook lines.
Timeline: Denis clip with the hook plate and word-group captions until his last word (+0.15 s), then the base short plays from just before its narration line 02 (the pain scene, `skip`), with the base's hook plate hidden by CSS. Narration, music and end card are the base's. Total length = cut + (base length - skip). If you change a base short, re-render its dd variant.
